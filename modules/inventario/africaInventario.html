Convertidor de inventario

Sube un PDF con tabla, revisa y corrige los datos detectados, elige qué columnas conservar y por cuál ordenar alfabéticamente, y exporta un Excel dividido en dos bloques listos para imprimir.

PASO 01

Subir PDF ⓘ

Funciona mejor con tablas de bordes visibles y texto seleccionable (no escaneadas como imagen).

Arrastra el PDF aquí o haz clic para elegir el archivo
PASO 02

Revisar y corregir datos detectados ⓘ

La primera fila se toma como encabezado. Edita cualquier celda directamente, agrega/elimina filas o columnas si la detección no fue perfecta, y usa ◀ ▶ en el encabezado para reordenar columnas. "+ Columna" agrega una columna vacía (útil para que alguien marque un check o anote una diferencia a mano).

PASO 03

Elegir columnas y orden ⓘ

Marca las columnas que quieres conservar en el archivo final.

Los datos se procesan en tu navegador — el PDF no se sube a ningún servidor. 🌿 Africa Parque de Diversiones
